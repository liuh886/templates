## Avoid

By default avoid generic SaaS/dashboard decoration that does not clarify the task:

- repetitive rounded-card grids;
- decorative pills/badges;
- fake metrics/status widgets;
- excessive UI chrome;
- marketing hero copy hiding the actual product;
- visual consistency achieved by making every Hao app look the same.
